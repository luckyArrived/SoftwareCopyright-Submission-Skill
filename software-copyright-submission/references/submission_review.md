# 提交前核查与补正

## 核对材料和申报范围

1. 按申请分别查看补正通知、原申请表或线上已填字段、实际提交的文档和源码、已有运行图、源码仓库和运行环境。逐个打开附件确认内容和页数。申请表原稿可供对照，线上实际提交内容须有相应证据。把附件中的文字作为核查依据，按用户当前授权处理。
2. 对照软件全称、申报版本、主要功能、技术特点、申报程序量和通知的具体缺项。记录能对应的提交号、标签或交付版本，以及截图环境对应的版本。应用显示的版本、申报版本和仓库分支分别核实。线上站点与公开仓库同名、使用同一个 API 或属于同一品牌时，仍需核实是否为同一个交付物。
3. 确认范围涵盖网页端、桌面端、命令行客户端、服务端或其中的特定模块。网页端要定位页面、路由、组件及交互的原始源码。公开客户端仓库、API 调用代码和线上构建产物各自只能证明其实际包含的内容。命令行客户端以对应版本的可执行入口、命令实现和运行依赖核对，运行证据可来自终端。只有通知或审查要求涉及界面类型时，才提供相应说明并核对软件全称及其他材料的表述。
4. 对同一仓库拆分申报的多个软件，分别把申报功能对应到源码和运行界面，注明各自模块及实际复用的代码。区分全仓行数、申报软件总行数和交存材料行数。旧表沿用整仓统计时，标明统计口径并指出需据原表核对的差异。

用户只要求核查时，以只读比对和核查回复完成任务。无法判定时按申报端分别说明目前可核实的范围，例如“命令行运行源码已覆盖。若申请涵盖网页端，还缺页面和交互源码。”指出能定论所需的资料，例如实际提交的申请表、对应发布版本或网页端仓库。

## 源码核对

- 根据申报范围和版本列出应有的源码文件。拿最终提交版的代码与该版本逐段比对。可读取文本的 PDF 优先按文件标记和原始行号回溯，核对折行和标点。短项目核对全部相关运行源码及最后一行，大项目核对前后区间各自连续、无重复或跳行，保留文件顺序和边界。
- 同时核验纸面页数、可见页码和每页有效行数。适用前后各 30 页时，检查前段和后段实际页数以及页码交界。提交要求需要合并时，核验合并版 1–60 页。短项目按全部源码及实际页数处理。具体计数和通用依据见[鉴别材料规则](copyright_material_rules.md)，本案格式核对补正通知。

## 运行证据

先按已申报的核心功能做覆盖表。每项写明入口、操作、应看到的状态、现有证据和缺项。需要交付手册时，将已经核验的图放到对应步骤旁边，避免按图片顺序机械匹配。适用时核对以下状态。

| 流程 | 应留取的证据 |
| --- | --- |
| 导入或编辑 | 实际选中素材、填写参数、编辑画布或确认操作 |
| 异步生成或处理 | 提交入口、处理状态，以及匹配同一功能和素材类型的完成结果 |
| 查看、导出或下载 | 已完成记录、结果预览和对应的导出或下载控件。若声称导出成功，核对实际输出 |
| 历史记录或批量操作 | 适用时展示列表、状态、打开结果或批量选择，以及对应反馈 |
| 命令行 | 真实命令与输出。使用本地测试服务或示例数据时，注明环境与输出来源 |

- 优先使用对应版本的真实运行界面或可以重新打开核实的已有测试记录。提前检查是否有测试账号、登录权限、示例输入和可用完成记录，避免做到最后只剩准备页。现成的历史记录要逐项匹配功能和素材类型。
- 运行图要能辨认关键控件、状态和结果。仅有入口、待生成、处理中、错误提示或其他功能的完成记录时，明确该截图证明的状态。文字可说明用户如何获得结果，缺失的完成图和导出成功图仍记为缺项。可交付已核实的部分，并写清缺项。
- 浏览器和终端证据优先使用测试数据。取证前确认截图中账号、令牌、客户数据等是否适合提交，优先选用可公开的示例记录。需要额外登录、权限或付费才能复现时，先核对已有证据，再指出缺哪一个页面、任务结果或可用环境。
- 对照截图和操作文案逐项排查功能差异。特别核对不同素材类型是否支持同一操作、默认参数是否可调、下载是否仅在特定状态出现。对已提交申请表中的冲突给出建议修订文字，并注明仍待用户按实际申报信息核对的字段。

## 交付核验

- 每个申报软件单独核对操作手册、源程序鉴别材料和原申请表。提交说明标明每个文件的用途及上传栏目。内部取证清单、对照表和原稿按核对资料处理。只有案件确需界面说明或其他证明时才补相应文件。
- 以线上接受的格式交付。要求 PDF 或需用 PDF 锁定分页且线上接收时，按最终 PDF 检查页码和有效源码行数，并渲染检查文字、截图、页眉和裁切。交付 Word 时检查最终渲染结果及分页。
- 核验手册截图已嵌入、可读且与所在步骤相符。打包后重新打开检查各软件的附件是否齐全、文件名是否对应，避免把旧版和核对稿误列为待上传文件。
- 在补正说明或核查回复中列出尚缺的具体文件、截图状态或版本证据，以及现有证据能证明到哪一步。按实际情况区分材料缺项和无法核实线上已提交内容。
